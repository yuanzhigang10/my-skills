# 配色与字号规约

## 怎么上色（不要乱选）

四步法：
1. **找分组**：图里有几层 / 几个分支 / 几个阶段
2. **每组一色**：从下方色板里挑 2-5 套
3. **容器浅色填充**（告诉读者"这块是整体"）
4. **内部节点白底 + 该组深色边框**（告诉读者"这些属于这个组"）

> **用户优先**：用户指定了色值/品牌色时，以用户为准。仅给 1-2 色时由你扩展到完整色板（浅底/深边框/灰连线）。
> 未指定时，**严格从下方色板中挑**，不要凭感觉自创 `#1664FF` `#14C9C9` 之类不在表里的色值。

## 字号规约

| 用途 | 字号 | weight |
|---|---|---|
| 主标题 | 24-30 | bold |
| 副标题 / 章节 | 18-22 | bold |
| 节点标题 | 16-18 | bold |
| 正文 / 标签 | 12-14 | regular |
| 辅助文字（日期、计数）| 12 | regular |
| 圆点编号 | 11-12 | bold |

**最小可读字号：12**（飞书画板缩放后再缩，文字< 12 几乎不可读）。

## 视觉一致性

| 参数 | 推荐值 |
|---|---|
| `borderWidth` | 2（边框清晰）/ 1（次要分组）|
| `borderRadius` | 8-10（统一圆角，整洁）|
| 同侧节点 gap | ≥ 8 |
| 有连线的 gap | ≥ 40（给箭头留空间）|
| 卡片 padding | ≥ 12 |
| 文字与背景对比度 | 正文 ≥ 4.5:1，标题 ≥ 3:1（WCAG 2.1）|

## 配色检查清单

每完成一张图，按这个清单自查：

- [ ] 同一逻辑分组用了相同色系（fill + border 配对，不是随机色）
- [ ] 不同分组之间至少 3 个色相步长（避免读者无法区分相邻分组）
- [ ] 强调元素（标题、鱼头、终点）用了 `#1F2329` 黑色或品牌主色
- [ ] 连线弱化为灰色（`#BBBFC4`），不抢节点注意力
- [ ] 没有用色板外的"自创色"
- [ ] 关键信息不只靠颜色区分——同时配了形状/边框/文字标签（色觉障碍友好）
