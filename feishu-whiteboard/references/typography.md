# Typography — 字号 / 行高 / 视觉权重

> 文字是画板里**信息密度最高**的元素。Typography 做得好的图，扫一眼就能抓到重点；做得差的图，看半天也不知道哪条信息更重要。

## 字号层级（严格 6 层）

不要用 14 一种字号撑全图——读者会失去阅读引导。

| 用途 | 推荐字号 | 字重 | 示例 |
|---|---|---|---|
| **主标题** | 24-32 | bold (700) | "事件归因 Skill 分层执行链路" |
| **副标题 / 章节** | 18-22 | bold (700) | "5 层架构 · 12 个步骤" |
| **节点标题** | 16-18 | bold (700) | "数据源取数" |
| **正文 / 标签** | 12-14 | regular (400) | "输出指标序列" |
| **辅助文字**（日期、计数、辅助说明） | 11-13 | regular | "12 人 · 杭州" |
| **代码 / 标识** | 11-12 | regular monospace | `RunEventAttribution` |

**规则**：
- 标题 / 正文之间字号差 ≥ 8（如 28 vs 14，对比明显）
- 同一层级用同字号（不要节点标题忽大忽小）
- 极限：飞书画板最小可读字号 **12**（≤ 11 缩放后糊）

## 字号 = 视觉权重

一张图你最想让读者**先看到的信息**用最大字号：

```
主标题 (28)          → "电商 GMV 下滑根因分析"
↓ 视觉锚点 (22)      → "GMV 同比 -18%"（鱼头里）
↓ 分类标题 (16)      → "流量端" / "转化端" / "商品端"
↓ 原因标签 (13)      → "搜索词排名下滑"
```

读者眼球的阅读路径会沿着字号大小自然引导。**不要让"最关键的洞察"用最小字**。

## 字色（与字号一起用）

| 色值 | 用途 |
|---|---|
| `#0F172A` 或 `#1F2329` | 主标题、关键文字 |
| `#475569` | 正文（强）|
| `#64748B` 或 `#646A73` | 辅助说明（弱）|
| `#94A3B8` | 几乎只在 hover 时强调（极弱）|
| 该分组的主色 | 分类标题（与边框配色一致）|
| `#FFFFFF` 反白 | 深色背景上的文字 |

**对比度自查**：
- 主标题：与背景对比度 ≥ 7:1（WCAG AAA）
- 正文：≥ 4.5:1（WCAG AA）
- 辅助：≥ 3:1
- 深色背景上**不要用 `#646A73` 这类中灰色**（对比度不够）

## 富文本混排（TextRun 数组）

DSL 的 `text` 字段支持 TextRun 数组，一行可混合多种样式：

```json
"text": [
  { "content": "获取", "bold": true, "fontSize": 18, "color": "#5178C6" },
  { "content": "  Acquisition", "fontSize": 12, "color": "#646A73" }
]
```

效果："**获取** Acquisition"（"获取"重字体 + 蓝色，副名小字 + 灰色，一行表达主名 + 副名）。

**何时用富文本混排**：
- 主名 + 副名（中英文对照）
- 数值 + 单位（`¥1.2M` vs `1.2M`）
- 强调一段中的某词（"流失 **18.5%**"）

**何时不用**：
- 多行文字 — 用多个 `text` 节点（更可控）
- 整行同样式 — 直接用 string

## 行高与间距

DSL 节点没有显式 `line-height`；行间距由相邻 `text` 节点的 `y` 差决定。

经验值：
- 14px 字号：相邻行 `y` 差 18-22px
- 12px 字号：相邻行 `y` 差 16-18px
- 16-18px 字号：相邻行 `y` 差 24-28px

**密集信息**（如鱼骨原因卡）取小值；**舒适阅读**（如说明段落）取大值。

## 中文 / 英文 混排

飞书画板硬编码 **Noto Sans SC**（覆盖中英）。注意：
- **中文字符 ≈ 1em 宽，英文字符 ≈ 0.6em 宽**——容器宽度按多语言混合估算
- 中英混排时单词之间加**半角空格**（"Claude × 飞书" 中的 × 两边都有空格）
- 不要用 `font-family` 强指定（被忽略），保持默认即可
- 极个别罕用字可能 fallback——避免冷僻字

## 字号选错的常见症状

| 症状 | 原因 | 修复 |
|---|---|---|
| "扫一眼不知道重点" | 字号同质化 | 标题加大到 26+，强调 bold |
| "标题看着普通" | 字号太小（< 22） | 拉到 26-30 |
| "标签密密麻麻读不清" | 字号 < 12 | 抬到 12-14 |
| "卡片里挤死" | 字号 + 行间距都偏小 | 字号 14、行距 20、padding 12 |
| "副标题没有副标题感" | 字号与正文一样 | 副标题取 14-16 + 灰色 |
| "看起来很 AI 生成" | 全 14px 黑色 | 加层级、加颜色变化 |

## 数字 / 数据的展示

- **大数字必加千分位**：`1,200,000` 比 `1200000` 易读 10 倍。脚本里用 `n.toLocaleString()`
- **百分比保留 1 位小数**：`18.5%`（一位）比 `18%`（虚假精度）或 `18.523%`（噪声）好
- **单位贴紧数字**：`100K` `¥1.2M`（不要 `100 K`）
- **趋势用箭头**：`↑12.5%` / `↓18.2%`（颜色对应正负）

## 标题措辞清单

| 弱 | 强 |
|---|---|
| "架构图" | "Next.js 14 全栈 React 架构" |
| "增长漏斗" | "下单转化漏斗 · 日活 100K 起步" |
| "里程碑" | "Claude 模型迭代里程碑 · 2024 Q1 → 2026 Q2" |
| "原因分析" | "电商 GMV 下滑根因分析 · 五维鱼骨图" |
| "结果" | "GMV 同比 -18%"（数据 + 方向）|

弱标题没有信息密度；强标题一行说完全图主旨。
